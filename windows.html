Ventajas de Windows

  • Compatibilidad total: Es el rey indiscutible para gaming y productividad pues soporta casi cualquier aplicacion de pc de forma nativa
  • Software especializado:La gran mayoria de software industrial, ingnieria, diseño pesado y herramientas empresariales estan diseñadas primariamente para Windows
  • Plug and Play: La mayoria de perifericos(impresoras, accesorios etc) funcionaran al momento de conectarlos, gracias a los drives universales ya incluidos
